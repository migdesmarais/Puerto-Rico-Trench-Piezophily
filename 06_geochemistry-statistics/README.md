# Geochemistry and environmental correlations

Statistical analyses relating sediment geochemistry to microbial biomass-linked
proxies, diversity, and JS1 relative abundance across the Puerto Rico Trench transect.

Analyses include depth-matched Spearman rank correlations among organic-matter
properties, redox variables, cell abundance, total adenylate concentration and
rarefied ASV richness, as well as a separate analysis of JS1 relative abundance
against sediment depth and geochemical variables.

Variables measured at different sediment horizons were paired within sites using
one-to-one depth matching. Oxygen concentrations were linearly interpolated to
target horizons and set to zero at and below the first measured zero-oxygen horizon.

P values for the 15 transect-wide correlations were adjusted together using the
Benjamini-Hochberg procedure. JS1 correlations were treated as a separate analysis
family and adjusted separately.
