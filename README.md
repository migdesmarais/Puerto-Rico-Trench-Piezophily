# Puerto Rico Trench piezophily

Code accompanying:

**Desmarais et al. (2026). Piezophilic activity dominates the Puerto Rico Trench deep subseafloor biosphere.**  
*bioRxiv*. https://doi.org/10.64898/2026.09.30.755482

## Repository structure

- `01_BONCAT-FACS-seq/` — Read quality control, taxonomic classification, contaminant filtering, and community-composition analyses of BONCAT-FACS-seq libraries.
- `02_MAG-recruitment/` — Read mapping and genome recruitment analyses.
- `03_JS1-phylogenomics/` — Genome quality control, taxonomy, phylogenomic reconstruction, and relatedness analyses.
- `04_JS1-comparative-genomics/` — Genome architecture, functional annotation, proteome physicochemical properties, KO-based ordination, and comparative statistical analyses.
- `05_JS1-16S/` — JS1 16S rRNA gene sequence clustering and relative-abundance analyses.
- `06_geochemistry-statistics/` — Statistical analyses relating microbial properties and JS1 abundance to sediment geochemistry.
- `metadata/` — Metadata and supporting input files used by the analyses.

## Data availability

Large sequencing datasets are not duplicated in this repository. Raw sequencing data are deposited in the NCBI Sequence Read Archive (SRA); accession information is provided in the associated manuscript.
